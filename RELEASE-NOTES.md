# Jude Study Room 0.6.1

Fixes the desktop sign-in connection after the classroom service address changed. Login, assignment saving, and file transfers use the current classroom address. The app can follow method-preserving redirects only between the two approved classroom addresses; credentials are never forwarded to other hosts.

Accounts, saved answers, grades, and files remain in the existing classroom service. Includes the current classroom interface and continues receiving lesson and interface updates without reinstalling.

Windows: use App updates to download and install this fix. Mac: download the arm64 ZIP, extract it, and replace the app in Applications. Because this changes the installed connection component, existing 0.6.0 installations need this one app update.
